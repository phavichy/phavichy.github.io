# Rules for this repo

This repo is **public**. Each folder is one short link: `phavichy.github.io/<folder>`.

- Only redirect pages or pages with no real data.
- Never commit crew data, sheet IDs, passwords, tokens or API keys.
- Every page carries `<meta name="robots" content="noindex, nofollow, noarchive">`.
- Keep folder names short and neutral (no airline or project names).

|---|---|
| `r3/` | Recency viewer (Apps Script web app, login required) |
